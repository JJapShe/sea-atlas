# Sea Atlas · 바다를 읽는 도감

현생 해양동물을 탐색하는 한국어 정적 도감. Dino Atlas와 Insect Atlas의 검색·관찰·이미지 관리 방식을 참고해 별도의 작은 앱으로 구현했다. 기존 두 프로젝트는 수정하지 않았다.

## 현재 항해 · 먹이활동·생태·상호작용 갤러리

- 미국투구게(`Limulus polyphemus`), 대왕오징어(`Architeuthis dux`), 향유고래(`Physeter macrocephalus`)를 첫 세 생물로 소개한다.
- 현재 구성은 33종마다 대표·먹이활동·생태 각 1장 이상, 총 106개 자체 제작 삽화·110개 갤러리 항목·등록 공개 파일 112개다. 연안·산호초·외해·심해·한랭 해역 생물을 제공한다. 향유고래–대왕오징어, 해달–자주성게, 흰긴수염고래–남극크릴, 아델리펭귄–남극크릴 상호작용은 관련 두 동물의 갤러리에 같은 원본을 연결한다. 모든 삽화는 ChatGPT로 제작하며 실제 사진과 구분해 표시한다.
- 이름·학명·별칭·특징 검색, 10개 탐색 분류, 5개 서식 환경, 활동 수심 필터를 제공한다.
- 종별 크기 측정 기준·분포·먹이·형태 단서·생태·원문 출처·삽화 제작 안내를 제공한다.
- 브라우저별 책갈피, 카테고리 안에서 움직이는 확대 보기, 종 상세 직접 링크를 제공한다.
- 같은 필터를 PC와 모바일에서 사용하며 네이티브 dialog와 키보드·포커스 복귀 흐름을 유지한다.

## 실행

`start-sea-atlas.cmd`를 실행하면 공개 파일 검사를 거쳐 도감을 연다. 기본 주소는 <http://127.0.0.1:8041>이다. Node.js와 Python이 필요하며 이 PC에 있는 런타임을 사용한다. 공개 폴더 `_site/`만 서비스한다.

검증: `node scripts/verify.mjs`

공개 폴더 만들기: `node scripts/build.mjs`

공개 도감: <https://jjapshe.github.io/sea-atlas/>

개인 계정 저장소: <https://github.com/JJapShe/sea-atlas>

`main`에 변경을 올리면 `.github/workflows/deploy-pages.yml`이 검증·빌드 후 `_site/`만 GitHub Pages에 배포한다. 저장소에는 앱 소스·문서·검증 스크립트·선정된 PNG를 보존한다. `work/` 제작 후보·운영 기록·이전 외부 사진은 저장소와 웹 공개에서 제외하며 원래 로컬 파일은 보존한다.

## 읽기 화면과 콘텐츠 원칙

읽기 화면은 5–12세 어린이를 염두에 둔다. 본문은 18px, 카드 이름은 24px, 보조 글씨는 최소 14px이며 글자 크기는 rem으로 지정한다. 모바일에서는 카드를 한 줄에 하나씩 보여주고 설명을 줄이지 않는다. 주요 버튼은 높이 44px 이상이다. 삽화는 카드·상세·썸네일에서 몸과 부속지가 잘리지 않게 표시한다.

`data/animals.js`에 종 데이터와 공개 갤러리가 있다. `assets/manifest.json`은 동일한 이미지의 제작·검수·파일 정보를 보존한다. 생성 삽화에는 제작 도구, 세부 모델명 미제공 사실, 정확한 원본·수정 프롬프트, 생성 시각, 육안 점검일·요약, PNG 크기와 SHA-256을 기록한다. 먹이활동·생태 그림은 `behaviorCheck`와 `behaviorSources`로 행동 근거와 재구성 한계를 함께 남긴다. 세부 모델명을 추정하거나 외부 사진의 출처·다운로드·라이선스를 생성 삽화에 붙이지 않는다.

사용자는 2026-10-03에 15종 전체를 ChatGPT 자체 제작 삽화로 전환하고, 종마다 최소 3장으로 먹이활동과 생태·다른 구도를 추가하는 작업을 명시적으로 승인했다. 생성 결과는 먼저 후보로 보관하고, 부모·독립 에이전트의 원본 크기 육안 점검과 수동 선정 기록을 거쳐 최종 공개 배열에 넣는다. 생성만으로 자동 승격하지 않는다. `visual-checked`는 드러난 핵심 형태를 눈으로 대조했다는 뜻이며 전문가 감수·전문 동정을 의미하지 않는다. `expertReviewed: false`를 유지하고 화면에서도 전문가 감수 전임을 알린다. 가려진 부위는 확인됐다고 주장하지 않으며, 행동 장면은 근거를 바탕으로 재구성한 교육 삽화로 표시한다.

제작·교정·검수 기록은 `work/chatgpt-production-20261003/`에 있다. `anatomy-cues.md`는 종별 형태 기준, JSON은 정확한 생성·수정 프롬프트와 후보 버전, `independent-review.md`는 독립 육안 판정과 확인 불가 부위를 기록한다. 수정본은 다시 확인하고 최종 선정 버전만 `assets/images/`에 연결한다. 제작 기록과 미선정 후보는 공개 빌드에서 제외한다.

생태 확장 기록은 `work/ecology-gallery-20261003/`에 있다. 단일 장면 후보 33장 중 부모·독립 에이전트가 대조한 최종 30장을 수동 선정했다. `BRIEF.md`, 각 후보 JSON, 행동 출처 문서, `reviewers-*.md`, `independent-review-dino.md`, `manual-selection.json`, `independent-selection-review.json`에 제작·교정·판정·선정 버전과 해시를 보존한다. 대왕오징어 먹이활동은 v3, 자주성게 먹이활동은 v2, 나머지 추가 그림은 v1이다. 향유고래 수면 생태 그림은 1774×887 파노라마 원본을 유지하며 다른 1536×1024 그림과 함께 `contain`으로 전체를 표시한다.

생물의 활동 수심 필터는 출처로 확인한 활동·관측 구간이다. 가능한 전체 서식 범위나 최대 잠수 기록 목록이 아니다. 크기도 총길이·외투막 길이·성별·군체 등 측정 기준을 함께 읽는다. 탐색 분류는 찾아보기 위한 묶음이며 계통도는 아니다.

## 검증 상태

검증 스크립트는 고유 ID·필수 3종·분류·서식·수심·출처, 종마다 검토 이미지 최소 3장 및 먹이/생태 장면 존재, 행동 근거, 생성/사진 스키마, 이미지 SHA-256, 실제 PNG 치수, manifest와 갤러리의 일치, 역할·검수 상태별 후보 배제, 삽화 대표 우선순위, 검색·복합 필터·책갈피를 검사한다. 빌드는 등록된 공개 파일만 `_site/`에 복사한다.

이전 15종·45장·등록 51파일 단계의 데이터 검사와 공개 빌드가 통과했다. 로컬 HTTP로 등록 파일 51개(그림 45장 포함)를 받아 공개 산출물과 바이트 단위로 대조했다. 실제 인앱 브라우저에서 15종 모두 세 장의 갤러리 연결을 확인하고, PC 1440px 및 모바일 390·320px의 확대·넘기기·가로 넘침 없음, 삽화 분류 내 순환, 키보드와 Escape 후 포커스 복귀를 확인했다. 향유고래 파노라마도 원본 치수와 전체 표시를 확인했다. 브라우저 오류·경고 로그는 없었다.

갤러리 설명은 16px이며 그림 영역을 3:2 비율로 넓혔다. 장면 제목과 행동 설명을 어린이가 읽기 쉬운 문장으로 정리하고 출처 링크를 확대 화면에 표시한다. 정확한 결과는 `work/ecology-gallery-20261003/browser-check-results.json`과 `preview-assets-check.json`, 화면은 `gallery-desktop.jpg`와 `lightbox-mobile.jpg`에 있다. 아래 과거 검사 기록과 구분한다.

## 대표 삽화 15장 전환 이력

2026-10-03 대표 삽화 15장·등록 21파일 버전의 검증을 완료했다. 당시 데이터 검사와 공개 빌드가 통과했으며 등록 파일 21개를 로컬 서버에서 받아 공개 산출물과 바이트 단위로 대조했다. 15종 모두 ChatGPT 자체 제작 삽화만 대표로 연결되어 있었다.

실제 인앱 브라우저에서 1440·900·390·320px의 가로 넘침이 없음을 확인했다. PC에서 15개 카드 이미지가 모두 로드되고 전체 그림을 맞춰 표시한다. 본문 18px·카드 이름 24px, 모바일 한 열·설명 생략 없음도 유지한다. 학명 검색·복합 필터·책갈피 새로고침·모바일 골라보기·삽화 분류·확대 보기·Escape와 포커스 복귀·향유고래 직접 링크 새로고침을 확인했다. 확인한 브라우저의 오류·경고 로그는 없었다.

최종 제작 요약은 `work/chatgpt-production-20261003/README.md`, 화면 검사 결과는 `browser-check-results.json`, 공개 파일 HTTP 대조는 `preview-assets-check.json`, 완성 화면은 `atlas-desktop.jpg`와 `mobile-lightbox.jpg`에 있다. 기존 사진 버전의 이미지 실패 후 복구 검사는 이번 전환에서 다시 실행하지 않았으며 기존 복구 동작을 유지했다.

## 초기 사진 버전 이력

첫 구현은 현생 15종·출처 대조 이미지 16장·등록 공개 파일 22개였다. 대왕오징어 표본 사진과 흡혈오징어 역사 삽화를 실물 사진과 구분했다. 사진의 원본 종 표기와 출처·라이선스를 대조한 `source-checked`는 전문가 감수나 사용자 승인을 뜻하지 않았다. 기존 photo/reference 데이터·검사 분기는 호환을 위해 유지한다.

`work/browser-check.cjs`와 당시 `work/` 결과·화면은 **과거 사진 버전의 검사 기록**이다. 그 기록을 현재 자체 제작 삽화 갤러리의 브라우저 검증 근거로 간주하지 않는다.

조사 판단과 확장 순서는 [PLAN.md](PLAN.md)에 있다.

## 상호작용과 새 생물 확장

2026-10-03에 큰돌고래·대왕쥐가오리·해양이구아나 3종과 9개 대표·먹이·생태 삽화, 상호작용 삽화 2개를 추가했다. 향유고래와 대왕오징어의 힘겨루기는 포식 및 빨판 흔적 자료에 따른 상상 재구성이며 실제 촬영·관측 순간으로 표시하지 않는다. 해달과 성게는 수면의 먹이 관계를 표현한다. 공유 삽화는 두 동물에 연결하되 원본 파일과 manifest는 한 번씩 보관한다.

최종 선정·후보 교정·원본 일치·독립 육안 검토와 공개 전달 검증 기록은 로컬 work/interactions-expansion-20261003/에 보존한다. 당시 검증은 18종·56개 이미지·58개 갤러리 항목·62개 공개 파일을 기준으로 했다.

## 심해생물 6종 확장

2026-10-03에 투명머리물고기(Macropinna microstoma), 검은바다악마(Melanocetus johnsonii), 펠리컨장어(Eurypharynx pelecanoides), 송곳니고기(Anoplogaster cornuta), 붉은배 빗해파리(Lampocteis cruentiventer), 유영해삼(Enypniastes eximia)을 추가했다. 각 종의 대표·먹이활동·생태 3장, 총 18장을 ChatGPT로 제작해 부모·독립 에이전트의 육안 대조 후 수동 선정했다. 기존 18종과 공유 상호작용 갤러리를 유지한다.

빗해파리는 자포동물과 구분해 별도 탐색 분류로 제공한다. 미확정 식단·먹이 탈취 가설·기관별 크기와 수심 범위를 구분하고, 한국어 설명용 이름에는 학명을 함께 표기한다. 삽화는 교육적 재구성이며 전문가 감수 전이다. 송곳니고기 대표 후보 v1/v2는 치아 방향이 불분명해 제외하고 v3를 선정했다. 최종 18장 버전·원본 일치·SHA·수동 선정·독립 육안 판정과 로컬/실제 Pages 전달·화면 검사 기록은 work/deep-sea-expansion-20261003/에 보존한다. 당시 검증 기준은 24종·74개 이미지·76개 갤러리 항목·80개 공개 파일이었다.

## 다양한 해양생물 9종 확장

흰긴수염고래(Balaenoptera musculus)·아델리펭귄(Pygoscelis adeliae)·남극크릴(Euphausia superba)·복해마(Hippocampus kuda)·개복치(Mola mola)·공작갯가재(Odontodactylus scyllarus)·푸른갯민숭달팽이(Glaucus atlanticus)·파란불가사리(Linckia laevigata)·대왕관벌레(Riftia pachyptila)을 추가했다. 새 종은 각각 대표·먹이활동·생태 3장 이상이며, 기존 미국투구게의 해변·푸른바다거북의 어린 개체 유영·대왕쥐가오리의 청소소 장면도 한 장씩 추가했다. 이번 추가는 32개 원본 이미지와 34개 갤러리 연결, 최종 33종·106개 ChatGPT 원본 PNG·110개 갤러리 항목·112개 공개 파일이다. 기존 24종의 필드와 74개 원본 이미지는 보존했다.

조류와 환형동물을 별도 탐색 분류로 제공한다. 복해마는 국내 종 목록의 이름과 학명을 대조하고, 설명용 한국어 이름은 학명과 함께 읽는다. 관벌레 성체는 입과 소화관이 없어 몸속 세균이 만든 영양을 받는다고 설명한다. 고래·펭귄의 크릴 먹이 관계는 근거에 따른 재구성이며, 실제 포획 성공이나 촬영 장면으로 표시하지 않는다. 제작·원문 조사·교정·부모 및 독립 육안 검토·수동 선정·현재 전달과 화면 점검 증거는 로컬 work/diversity-expansion-20261003/에 보존한다. 공개 전달 완료 판정은 해당 폴더의 최신 completion.json 및 public-delivery.json·public-browser-check.json을 기준으로 한다.
